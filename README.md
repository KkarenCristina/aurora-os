# 🌅 Aurora OS

**Um sistema pessoal de organização de vida** — objetivos, projetos, hábitos, planejamento, saúde, finanças, cultura e memórias, tudo em um só lugar, com login e dados privados por usuário.

🔗 **[Acesse o site](https://aurora-os-neon.vercel.app)**

Inspirado em um template pessoal de Notion, recriado como uma aplicação web completa, multiusuário, com autenticação e banco de dados na nuvem.

## ✨ Funcionalidades

- **Dashboard** — visão geral do dia, com progresso visual dos hábitos e tarefas
- **Meu Plano de Vida** — espaço para reflexão pessoal (quem sou, visão de futuro, carta para mim)
- **Objetivos** — metas organizadas por prazo (foco atual, 2026, 2027, antes dos 30, sonhos)
- **Projetos** — plano de ação com fases e checklists
- **Tarefas** — rastreador de hábitos diário com progresso mensal
- **Planejamento** — prioridades mensais e planejamento semanal detalhado
- **Saúde** — peso, IMC, medidas corporais, treino e corrida
- **Finanças** — controle mensal de renda, gastos, dívidas e patrimônio
- **Vida** — gratidão, pequenas alegrias e experiências desejadas
- **Cultura** — livros, filmes/séries e músicas favoritas
- **Experiências** — registro de momentos vividos
- **Caixa de Entrada** — anotações rápidas

Cada usuário cria sua própria conta e vê apenas os próprios dados.

## 🛠️ Tecnologias

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- [Supabase](https://supabase.com) — autenticação e banco de dados PostgreSQL com Row Level Security
- [Tailwind CSS](https://tailwindcss.com)
- Hospedado na [Vercel](https://vercel.com)

A ideia, a estrutura de organização de vida e todas as decisões de produto (o que rastrear, como organizar cada módulo) são minhas, originadas de um template pessoal que eu já usava no Notion. A implementação técnica (código, banco de dados e deploy) foi construída com apoio do **Claude (Anthropic)**, com quem colaborei ao longo de todo o processo — da estrutura do banco de dados até a configuração do deploy.
